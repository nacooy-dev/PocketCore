# PocketCore 对话助手使用指南

## 概述

PocketCore对话助手是一个基于LLM的智能对话系统，能够理解用户请求并智能调用各种工具来完成任务。它结合了PocketFlow框架的优势和多种工具的能力，为用户提供一体化的智能助手体验。

## 核心功能

### 1. 智能对话理解
- 理解自然语言请求
- 识别用户意图
- 提供自然流畅的对话体验

### 2. 工具调用能力
- 计算器工具：执行数学计算
- 翻译工具：多语言翻译
- 搜索工具：网络信息检索
- 文件系统工具：文件读写操作
- 模型发现工具：查看可用LLM模型

### 3. 上下文管理
- 维护对话历史
- 保持任务上下文
- 支持多轮对话

## 架构设计

```
mermaid
graph TD
    A[用户输入] --> B[对话助手]
    B --> C[LLM理解]
    C --> D{需要工具?}
    D -->|是| E[工具调用]
    E --> F[结果处理]
    F --> G[LLM整合]
    G --> H[返回结果]
    D -->|否| H
    H --> I[用户]
```

## API使用

### 对话接口

**Endpoint**: `POST /dialogue`

**请求体**:
```json
{
  "message": "用户输入的消息",
  "conversation_id": "可选的会话ID"
}
```

**响应**:
```json
{
  "response": "助手的回复",
  "conversation_id": "会话ID"
}
```

### 示例

```bash
# 基本对话
curl -X POST http://localhost:8000/dialogue \
  -H "Content-Type: application/json" \
  -d '{"message": "你好"}'

# 使用工具
curl -X POST http://localhost:8000/dialogue \
  -H "Content-Type: application/json" \
  -d '{"message": "计算 123 + 456"}'

# 复杂任务
curl -X POST http://localhost:8000/dialogue \
  -H "Content-Type: application/json" \
  -d '{"message": "翻译 Hello, how are you?"}'
```

## 可用工具

### 1. 通用聊天工具 (general_chat)
用于一般性对话和问答。

### 2. 网络搜索工具 (web_search)
模拟网络搜索功能。

### 3. 计算器工具 (calculator)
执行数学计算。

### 4. 翻译工具 (translator)
翻译文本内容。

### 5. 模型发现工具 (model_discovery)
发现并列出所有可用的LLM模型。

## 使用示例

### 简单对话
```
用户: 你好
助手: 你好！我是PocketCore智能对话助手。有什么可以帮助你的吗？

用户: 你能做什么？
助手: 我可以帮你完成各种任务，比如：
1. 数学计算
2. 文本翻译
3. 信息搜索
4. 文件操作
请告诉我你想要做什么？
```

### 工具调用
```
用户: 计算 123 + 456
助手: 计算结果: 123 + 456 = 579

用户: 翻译 Hello, how are you?
助手: 翻译结果: 你好，你好吗？

用户: 查找人工智能的发展历史
助手: 搜索结果: 关于'人工智能的发展历史'的搜索结果...
1. 人工智能发展简史
2. AI技术演进时间线
3. 机器学习发展里程碑
```

## 高级功能

### 多步骤任务
对话助手可以处理需要多个步骤完成的复杂任务：

```
用户: 计算 123 * 456 然后翻译结果
助手: 我将帮您完成这个任务。
首先计算 123 * 456 = 56088
然后将结果翻译为中文：五万六千零八十八
```

### 上下文保持
助手能够维护对话上下文，支持多轮对话：

```
用户: 我叫张三
助手: 你好，张三！有什么可以帮助你的吗？

用户: 我的年龄是30岁，你认为我应该投资什么？
助手: 基于您30岁的年龄，我建议您可以考虑以下投资方式：
1. 股票基金：适合长期投资
2. 指数基金：风险相对较低
3. 定期存款：保证本金安全
```

## 配置与部署

### 环境变量
```bash
# LLM提供商配置
DEFAULT_LLM_PROVIDER=ollama  # 或 openai, anthropic, zhipu, openrouter
OLLAMA_BASE_URL=http://localhost:11434
OPENAI_API_KEY=your_openai_api_key
ANTHROPIC_API_KEY=your_anthropic_api_key
ZHIPU_API_KEY=your_zhipu_api_key
OPENROUTER_API_KEY=your_openrouter_api_key

# 其他配置
DEBUG=false
```

### 启动服务
```bash
# 启动Web服务
python api.py

# 或使用uvicorn
uvicorn api:app --host 0.0.0.0 --port 8000
```

## 错误处理

### LLM不可用
当配置的LLM服务不可用时，对话助手会：
1. 返回错误信息
2. 仍然可以执行本地工具
3. 提供降级服务

### 工具执行失败
当工具执行失败时，系统会：
1. 捕获异常
2. 返回错误信息
3. 继续处理其他任务

## 故障排除

### 常见问题

1. **LLM调用失败**
   - 检查服务是否运行
   - 验证API密钥
   - 确认网络连接

2. **工具执行错误**
   - 检查工具配置
   - 验证参数格式
   - 查看日志信息

3. **响应延迟**
   - 检查网络状况
   - 优化工具性能
   - 考虑使用缓存
